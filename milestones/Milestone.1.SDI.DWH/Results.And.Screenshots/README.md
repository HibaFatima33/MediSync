# DWH results and screenshots

This folder contains saved outputs that help explain and check the Phase 1 data warehouse implementation.

- The three sample CSVs each preview up to 25 rows from a SQL answer. Full current answer CSVs are created in Project.Data.And.Results/results when the pipeline runs.
- validation.json records warehouse row counts, unresolved links and the known source location conflicts from the saved load.
- monitoring contains recorded row counts, timings, date coverage and database sizes used by the Power BI monitoring page.
- screenshots contains the source counts and successful Airflow run screenshots.
