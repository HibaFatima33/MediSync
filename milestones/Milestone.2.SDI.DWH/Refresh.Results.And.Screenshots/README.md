# Refresh results and screenshots

This folder holds the counts and screenshots for the Milestone 2 refresh demonstration.

- `M2.DuckDB.Counts.After.Two.Refreshes.png` is the original terminal screenshot with the DuckDB counts after both refreshes.
- `Milestone.2.SDI.DWH.Refresh.Counts.csv` and the `Refresh.1.Sales.501000.png` / `Refresh.2.Sales.502000.png` images show the prepared starting data and its two synthetic monthly batches.
- `Dashboard.2025.Historical.View.png` shows a saved dashboard view with 2025 selected. Choose 2026 in Power BI to see the newer months.
- `archive/Previous.Five.Task.Run.png` is an older Airflow screen. The current DAG has four tasks, so do not use this archived screenshot as proof of the current workflow.

After a successful Airflow run, verify the DuckDB counts and refresh the Power BI report separately in Power BI Desktop with **Home → Refresh**.
